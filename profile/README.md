Free, open-source tools that run on your own computer, for people and for AI agents: a CLI with `--json`, plus a local page or MCP server where it helps. No accounts, no servers, no telemetry.

| Tool | What it does | Download |
|---|---|---|
| [barcode-read](https://github.com/nowmyagentcan/barcode-read) | Read QR codes and barcodes (QR, Data Matrix, PDF417, Aztec, EAN/UPC, Code 128, GS1 DataBar and more) from photos, screenshots, scans, TIFF faxes and PDF pages, with JSON output | [latest release](https://github.com/nowmyagentcan/barcode-read/releases/latest) |
| [date-calc](https://github.com/nowmyagentcan/date-calc) | Count business days and hours with official public holidays for 250 countries, add working days, list holidays, and convert dates between Gregorian, Islamic, Hebrew, Chinese, Persian and Nepali calendars | [latest release](https://github.com/nowmyagentcan/date-calc/releases/latest) |
| [time-cron](https://github.com/nowmyagentcan/time-cron) | Explain a cron schedule (Unix, Quartz, AWS EventBridge) and list its next runs in any time zone, with each scheduler's daylight-saving rules | [latest release](https://github.com/nowmyagentcan/time-cron/releases/latest) |
| [validate-identifier](https://github.com/nowmyagentcan/validate-identifier) | Check IBANs, VAT numbers, phone numbers, emails, LEIs, ABNs, Swiss UIDs, EORI and Peppol IDs offline by format and check digits, or live against VIES, HMRC, GLEIF and the other official registries | [latest release](https://github.com/nowmyagentcan/validate-identifier/releases/latest) |
